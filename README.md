# 📖 Project Overview

A modern and interactive **Rock Paper Scissors** game built using **HTML5**, **CSS3**, and **Vanilla JavaScript**.

The game allows users to play against the computer with instant result evaluation, live score tracking, and an intuitive user interface. It demonstrates fundamental JavaScript concepts including DOM manipulation, event handling, random number generation, conditional logic, and dynamic UI updates.
